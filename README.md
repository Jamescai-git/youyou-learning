# 优优教育 · 拼音闯关

面向人教版一年级上册语文拼音学习者的单文件游戏化学习网站。

## 线上地址

https://jamescai-git.github.io/youyou-learning/

手机和电脑都可以直接打开，后续游戏菜单会继续加在这个网站主页。

## 内容

- 6 个学习单元，20 个知识点
- 覆盖单韵母、声母、平翘舌音、复韵母、鼻韵母、整体认读音节、声调和拼读
- 每个知识点包含 emoji 图示、分步讲解、小妙招和生活例子
- 6 种游戏：分配、摆放、捕捉、归类、建构、操作模拟
- 18 星进度、家长中心、浏览器本地存档、离线音效和撒花动画

## 打开方式

直接双击 `index.html`。整个网站不需要联网、服务器或安装依赖。

手机上可将文件放入“下载”文件夹，再用 Chrome、Edge 或系统浏览器打开。

## 记录说明

学习记录保存在当前浏览器的 `localStorage` 中。清理网站数据或换浏览器后，记录会重新开始。
